# 第二轮：更换底座与自动优化实测（2026-10-18）

本轮已换用 **MiniLM-L6-v2（隐私）与 CodeT5-small encoder（代码）**，冻结编码器后实际训练线性／深度分类头，运行有限预算自动配置搜索。没有将冻结编码器实验描述为全参数底座微调。

研究方法参考 AutoProver/AIProver 的候选验证与诊断反馈、autoresearch 的固定预算 keep/discard 流程，以及先定义验收规则的 AutoSciRub。实现的是可执行实验合同与有限搜索；没有运行 Solidity/Lean 证明器，也不构成模型正确性的形式化证明。来源与固定模型版本见 README.md 和 program.md。

## 本轮结论

- **代码方案保留为有改善的研究候选**：确认集 balanced accuracy 50.6% → 56.6%，AP 0.576 → 0.685。仍未通过部署验收，不能用于自动阻断。
- **隐私迁移没有证实收益，不作为升级发布**：MiniLM 方案确认集 balanced accuracy 53.1%，Tiny 对照 56.0%。验证集改善没有复现，不能以验证分数替代确认结果。
- 32 组配置、全部 keep/discard、四组胜出配置的三种子结果均保留。发布的是本轮已冻结模型和诊断材料；没有使用确认结果继续调参。

## 配对差异与验收

- **privacy**：新底座相对同协议 Tiny 对照，三种子平均 balanced accuracy 差值 -0.029；主种子配对 group bootstrap 95% CI [-0.099, +0.004]。确认集 Recall≥70% 且 FPR≤5% 的三个种子通过情况：`[False, False, False]`。
- **code**：新底座相对同协议 Tiny 对照，三种子平均 balanced accuracy 差值 +0.060；主种子配对 group bootstrap 95% CI [+0.039, +0.084]。确认集 Recall≥70% 且 FPR≤5% 的三个种子通过情况：`[False, False, False]`。

验收门槛只是一项实验条件。通过也不自动等于生产安全；未通过明确保留失败，不改动内核策略。差异包含所选分类头及其预算效果，不把它解释成纯底座能力的因果估计。

## 自动实验账本与成本

| 任务／底座 | 选择配置 | 搜索 trial 数 | keep / discard / error | 编码成本(s) |
|---|---|---:|---|---:|
| privacy/tiny | `{"kind": "mlp", "view": "evidence", "lr": 0.001}` | 8 | 4 / 4 / 0 | 35.0 |
| privacy/new | `{"kind": "mlp", "view": "evidence", "lr": 0.001}` | 8 | 5 / 3 / 0 | 449.2 |
| code/tiny | `{"kind": "linear", "view": "meanmax", "C": 0.1}` | 8 | 3 / 5 / 0 | 42.7 |
| code/new | `{"kind": "linear", "view": "mean", "C": 1}` | 8 | 2 / 6 / 0 | 588.2 |

每组 fit/selection 预算 30 秒；预训练编码的缓存成本单列，不宣称不同底座总计算成本相同。每个任务的 16 组配置完整保留，之后只复跑选定配置的两个额外种子。源码从配置选择前固定，评测后的搜索会被脚本拒绝。

## 检查与局限

数据散列、group 隔离、有限特征、源样本顺序／标签对应、冻结权重散列均通过可执行检查；数字 JSON 导出与本地已训练模型的预测一致性见 `head_exports.json`。确认／回归逐样本预测和全部指标、置信区间保留。

- privacy 新底座编码 14783 个片段、22,713,216 个冻结参数；受预算选择的 token 覆盖 2293776/3936896，截断单元 1774/5061。这不是无损完整上下文。
- code 新底座编码 10785 个片段、35,316,480 个冻结参数；受预算选择的 token 覆盖 1852637/9688068，截断单元 8244/10785。这不是无损完整上下文。

重复验证搜索、语料近重复、标注分歧和预训练重叠仍可能影响结论。这里的证书证明的是有限实验条件通过，不证明标签、真实授权、因果关系或模型语义安全。尚无真实 Agent/eBPF 回放闭环和中文评测，也没有把“代码有缺陷”升级为“Agent 造成漏洞／破坏”。
