# 行为可视化

在 Web 工作台的「观测分析 → 行为可视化」打开 `/behavior`。该页面将收到的事件按文件访问、网络通信、进程执行和其他信号分成四条时间轨道：越靠近「现在」刻度，事件越新。普通事件显示圆点；风险分数达到 60、语义告警，或记录了 ALERT / BLOCK / DENY 决策的事件显示菱形。

## 使用方式

- 选择进程，可聚焦精确 PID；时间窗支持 30 秒、60 秒和 5 分钟。
- 点击行为分类可聚焦事件流，其他轨道变淡；「仅需关注」同时突出轨道和列表中的需关注证据。底部仪表按当前 PID 和时间窗汇总。
- 点击轨道节点或右侧事件，查看原始操作、目标、PID、时间、风险、决策、返回值和事件 ID。在实时模式中，可进入该 PID 的执行追踪。
- 暂停仅冻结页面展示，Web 接收缓冲继续工作；恢复后合并待显示记录。离开页面会关闭该页面的连接和计时器。
- 「演示回放」使用有独立 ID 前缀的合成数据，不与真实事件混合，也不提供跳转真实 PID 的入口。它不会启动采集器或修改后端策略。可通过 `/behavior?demo=1` 直接预览。

页面跟随系统浅深色和减少动效设置，提供中文与英文界面。轨道节点可用 Tab 聚焦，Enter 或空格查看证据；窄屏将分类控件移到轨道下方，所有事件也可以通过原生按钮列表访问。

## 关注事件、选择转盘与回放定位

「行为导航台」提供六项转盘：全部、文件、网络、进程、其他、需关注。点击扇区直接应用；滚轮或方向键预选，中心按钮或 Enter/Space 确认；拖动背景后释放可旋转选择。Home/End 跳到首末项，Escape 取消预选或拖动。

「优先核查」将同一进程、会话、操作、目标和决策的重复行为折叠，保留全部事件 ID。可按风险分数或最近发生排序；卡片进入该组评分最高的原始证据，并分别显示最近时间和记录数。查看状态仅在本次页面会话中保存，不表示风险已解决，也不降低风险计数。点击关注时间轴的峰值可直接打开该时间段中评分最高的证据。

演示回放支持拖动进度、0.25×/0.5×/1×/2×/4× 速度、循环开关、从头播放，以及上一/下一关注时刻。拖动或跳转会暂停显示。时间显示相对当前展示时刻，暂停时冻结；回放使用演示时钟。

## Three.js 3D 演示

打开 `/behavior?demo=1&view=3d`，或在行为轨道标题栏选择「3D 空间」。四类行为分别位于不同高度和倾角的立体轨道，普通事件为圆点，需关注事件为菱形。轨道位置仍由事件时间决定，镜头运动不改变证据或统计。

- 拖动旋转、滚轮或双指缩放；聚焦画布后可用方向键旋转、加减键缩放、R 重置。
- 「自动环绕」控制镜头；暂停显示会同时冻结回放和自动运动，仍可手动检查视角。系统减少动效开启时自动环绕禁用。
- 点击立体节点、右侧事件流，或展开「键盘选择事件」，都会打开同一份事件证据。进程、时间窗、分类与关注筛选继续生效。
- 3D 每类最多绘制 24 个事件、总计 96 个；优先保留选中节点和高风险节点，再填入最近记录，避免重要证据被普通事件淹没。视图不可见时停止动画，退出时释放 WebGL 资源。
- 透视/俯视/侧视、分层展开、事件尾迹与聚焦选中方便检查密集节点。专注全屏保留来源、暂停与数据间隙提示；退出全屏返回工作台。
- WebGL 初始化失败或上下文丢失时显示平面轨道，可通过「重试 3D」恢复。

Three.js 作为本地打包依赖按需加载；演示使用已标注的合成数据，无需连接采集器。

## 数据范围与状态

Web 复用现有认证上下文，通过 `/ws/envelopes` 接收 protobuf EventEnvelopeBatch，连接成功后从 `/events/recent?limit=1000` 补取最近记录，按事件 ID 去重。最多保留 3,000 条事件，轨道每类最多画 24 个节点，事件流最多展开最近 12 条；仪表统计全部保留且在时间窗内的记录。缓存计数与后端持久化不是同一概念。

断开、补取中、补取失败、等待新事件和暂停有独立提示。补取失败时保留已有记录并提供重试；断线或解码失败后的连续性提示会保留。每次只补取最近 1,000 条，没有连续游标，不能保证断线间隙完整。

时间窗按事件接收/入库时间计算。未来记录不计入当前窗口；明显时钟偏移会提示。事件速率为最近五秒实际保留记录数除以五秒，不使用动画速度或模拟数字。风险和策略决策不单独证明内核已阻断；请检查返回值和完整审计证据。没有事件不表示设备安全。

## 原生 MyGo Desktop

在桌面端「监控工作台 → 行为轨道」进入。页面使用原有的内存事件摘要和采集状态，提供同心时间轨道、30 秒/60 秒/5 分钟窗口、精确 PID 聚焦、分类选择、最近五秒速率、网络字节和需关注证据。节点可查看摘要，并进入现有的完整事件证据。桌面端复用 1,200 条有界摘要，每类最多绘制 24 个节点；原生控件和绘图使用 MyGo 系统主题、文本缩放和高对比设置。

桌面端的暂停仅冻结该页面的投影，采集和其他页面继续运行。该原生页面使用真实采集摘要；Web 的合成演示回放仍是单独的预览入口。

## 验证

纯数据模型测试：

```bash
cd frontend
bun test tests/behavior-model.test.ts
bun run build
```

浏览器回归需要已启动的前端、Chromium 和可用的 playwright-core：

```bash
cd frontend
PLAYWRIGHT_MODULE=/path/to/playwright-core/index.mjs \
  CHROMIUM_PATH=/usr/bin/chromium BEHAVIOR_URL=http://127.0.0.1:5173 \
  bun scripts/test-behavior-browser.mjs
```

导航台验收可运行 `bun run test:behavior-navigation-browser`，覆盖关注分组/时间峰值、查看状态、转盘点击/键盘/滚轮/拖动、回放定位/速度/章节和 3D 分层/视角/尾迹/聚焦/全屏。

Three.js 的真实 WebGL 验收可使用相同环境运行 `bun run test:behavior-three-browser`，覆盖 WebGL2 场景、节点射线点选、冻结动画、键盘视角、进程/分类筛选、减少动效、浅深色、四种视口宽度、上下文丢失与重试，以及反复切换后的画布清理。

测试使用独立浏览器和本地 protobuf / WebSocket / HTTP 响应，覆盖回放隔离、暂停恢复、PID/时间窗/关注筛选、键盘证据检查、历史去重、重连补取失败及重试、浅深色、英文、减少动效、高对比和 375/768/1280/1920px 宽度。它不替代真实内核采集验证。

视觉布局参考用户提供的[行为可视化视频](https://x.com/chunxiangai/status/2121502422770348237)和截图，采用项目现有的语义配色和无障碍约定。
