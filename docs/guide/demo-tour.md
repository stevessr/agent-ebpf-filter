# 演示导览：从内核事实到 Agent 证据链

本页是 **2026 年 10 月代码版**的产品导览。日常用户先看「明镜高悬」桌面，研究与系统策略才进入 Vue Web 工作台。演示原则：**先核实采集状态，再观察行为，最后有条件地验证策略**。

::: warning 使用前提
真实 eBPF 采集需要 Linux、可用内核能力与适当授权。页面截图、离线事件或一个空白列表不能证明内核已经挂载、规则已经生效或机器安全。下面的命令只在你控制的开发机/虚拟机上执行。
:::

## 演示顺序

| 顺序 | 展示 | 观众应该理解什么 | 必备条件 |
| --- | --- | --- | --- |
| 1 | 「我的设备」与「系统诊断」 | 采集器、事件流、系统流是三个需要独立核实的状态 | 桌面可启动 |
| 2 | 事件与优先核查 | 风险分、告警、阻断与普通事件不是一个概念 | 有实际事件 |
| 3 | Agent 域名监控 | 有网络目标线索不等于获得了请求内容 | 有带 Agent 归因的网络摘要 |
| 4 | Agent 会话与派生图 | Agent 的 OS 子进程 ≠ 已确认的 SDK SubAgent 调用 | 实时系统进程快照 |
| 5 | 文件管理与原生编辑器 | 普通用户文件 I/O 与特权策略服务保持隔离 | 当前用户对演示目录有权限 |
| 6 | 跟踪范围与路径权限 | 观测注册、降噪与内核访问阻断是不同操作 | 仅查看可无策略权限 |
| 7 | Web 工作台与验证 | 深度研究、Hooks、MCP、指标及内核 smoke 有独立的操作入口 | 独立启动 Web/后端 |

## 第一步：准备系统

在仓库根目录：

```bash
make os-enforcement-preflight
make os-enforcement-check
make renew-desktop-dev
```

前两条为能力检查；第三条以原生 MyGo 开发方式启动桌面。另一条独立路径是 `make dev` 启动 Vue Web 开发环境，二者**不是同一个 UI**。文档单独预览使用 `bun install && bun run docs:dev`。

桌面入口、后端打包和权限说明见 [Renew 使用说明](/frontend/renew)；完整命令见 [快速开始](/guide/quick-start)。

## 第二步：认识健康状态

打开 **我的设备**：先判断后端连接、eBPF collector 健康、事件传输与系统快照状态，然后看最近活动及优先核查。若出现断连、流回退或丢弃计数，点击 **系统诊断**，不要把「暂无风险」当作采集成功。

**暂停事件**只是暂停前端展示与摘要合并，不会停止内核采集或安全策略。事件页的风险滑块和可见条数控制只改变当前已加载的摘要集合。

## 第三步：产生可解释的本机事件

可在独立普通终端执行：

```bash
mkdir -p /tmp/agent-ebpf-vitepress-demo
printf 'observed locally\n' > /tmp/agent-ebpf-vitepress-demo/note.txt
cat /tmp/agent-ebpf-vitepress-demo/note.txt
python3 -c 'import os; print("demo PID:", os.getpid())'
```

在 **事件** 页面按进程、PID、风险或事件类型查询；若没有事件，检查采集健康、跟踪注册与降噪规则。默认新配置会降低部分 `/tmp` 和 `/proc` 的低风险噪声，因此**不要用这组临时文件来承诺一定出现告警**。要展示文件事件，应在用户授权的非降噪测试目录注册一个明确的跟踪路径。

实际进程、文件与 syscall 关系来自已收到的证据；事件详情需要显式打开，离开后不应把完整敏感 payload 长期保留在桌面 UI。

## 第四步：查看 Agent 联网目标

在 **Agent 域名监控** 中按 Agent、域名或 IP 搜索，查看风险与会话统计，并从条目跳转到相应事件。它基于已有网络摘要里的 Host/SNI/Domain/DNS 或 IP-only 线索，**不**代表逐请求账单、模型 Token 用量或完整 TLS 内容。DoH、ECH、缓存和未采样流量可导致只有 IP。

如需审查 Claude Code / Codex 的本地声明，可在该页手动点击 **读取本机配置**：这是有界、只读、白名单字段抽取，不执行 MCP/Hook 命令，不保证是 CLI 实际生效的运行时配置。

## 第五步：Agent → SubAgent 派生

打开 **Agent 派生**（或从 **进程** 页跳转），选择当前识别到的 Agent 主进程：

- **放射图**：按实时 PID/PPID 展示进程派生层级，选择节点查看该进程相关事件。
- **瀑布图**：按进程启动时间与当前快照展示观察区间，**不是** SubAgent 任务耗时或真实退出时间。
- 黄色的「子 Agent 候选」要求该后代自身也是可识别的 Agent 可执行程序，普通 `bash`/`python` 子进程不会被直接升级成逻辑 SubAgent。

两个视图使用同一选中 PID。数据限制为单图 72 节点、6 层，依赖在线 `/ws/system` 快照；断线或 PID 重用时不允许拼接虚构关系。**同进程、跨 RPC、跨主机的逻辑 SubAgent 不会仅凭 OS 进程树被证明。**

如需生命周期信号，可在 Web Hook 管理页**分别选择** Claude Code 的 `SubagentStart`、`SubagentStop`，安装后重启 Claude 会话。Hook 的开始/结束信号仍不自动证明完整的调用关系或准确执行时长。

## 第六步：文件与路径保护

桌面 **工具 → 文件管理 / 原生编辑器** 可在后端离线时独立运行：创建测试文本、双击编辑并保存。编辑器遵守普通用户权限、拒绝符号链接/设备文件并在检测到外部修改时拒绝覆盖。此处的文件编辑 **不是** 利用 root 后端修改文件。

在 **跟踪范围** 中登记具体文件或递归路径前缀，仅决定观察范围；在 **路径权限** 中进行 BPF LSM **精确普通文件路径**读/写阻断，则需 `policy_management`、内核支持和二次确认。两者不能混为一谈。真实系统关键文件不要用于演示阻断。

## 第七步：进入 Web 深度工作台

Vue 工作台仍承担 Dashboard、Network、Execution Graph、Hooks、Config、ML/Plugins 等研究管理能力：

```bash
make dev
```

如果展示 cgroup 网络阻断或 BPF LSM 拒绝，应先通过 preflight，并在隔离环境选择**临时目标**；结合 API 状态、内核计数器和实际系统调用失败结果验证，不能只展示已保存的配置。

## 演示中必须说明的限制

1. Agent 归因依赖 PID/run/Hook 的可信证据，无法保证恢复已退出进程或跨 RPC 的完整历史。
2. 日常桌面只持有有界、经过上游脱敏的事件摘要；过滤与暂停不是内核安全动作。
3. 内核策略有明确的精确匹配范围；不自动得到目录树沙箱、CIDR 防火墙或 root 对抗能力。
4. 组件 IPC、memfd 共享数据面和 Collector–Engine 分离包含**实验/opt-in**路径，不能宣传成默认生产拓扑。
5. TLS 明文采集与系统命令执行都属于需要显式启用、充分授权的高风险功能。
