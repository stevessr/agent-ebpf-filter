# 📊 Dashboard（事件流工作台）

Dashboard 是 **Agent eBPF Filter** 的核心行为观测面板，提供高并发、实时的系统调用（Syscall）事件流瀑布，帮助开发者与审计人员实时跟踪 AI Agent 及其派生子进程的底层行为。

---

## 1. 界面功能分区

```text
+-----------------------------------------------------------------+
| [顶部统计栏] 事件总数 / 拦截数 / 异常评分 / 当前脱敏级别           |
+-----------------------------------------------------------------+
| [筛选条件面板] PID / Comm / 行为类型 / 时间窗口 / 风险等级          |
+-----------------------------------------------------------------+
|                                                                 |
| [实时事件流瀑布列表 (虚拟化滚动加载)]                            |
|  * 09:50:01 - execve   - git status (PID 12455)                 |
|  * 09:50:02 - openat   - /workspace/.env (PID 12455) [SECRET]   |
|  * 09:50:03 - connect  - 192.168.1.1:80 (PID 12455)             |
|                                                                 |
+-----------------------------------------------------------------+
| [右侧详情与 Strace-Style 抽屉]                                  |
|  - 完整系统调用参数解析 (argv, flags)                            |
|  - 耗时统计、调用堆栈、关联的 Tool Call / Agent Run 元数据       |
+-----------------------------------------------------------------+
```

---

## 2. 核心特性

### 2.1 实时零拷贝管道展示
后端通过 eBPF Ringbuf 采集事件并以低开销的 WebSocket 推送给前端。前端采用高性能虚拟滚动（Virtual Scroll）技术，支持万级并发事件的流畅渲染，避免 DOM 节点过多导致的浏览器卡死。

### 2.2 多维关联过滤
用户可以在筛选面板中，对以下关键维度进行组合筛选：
* **Agent Run / Conversation ID**：快速聚合单次大模型任务（Run）产生的行为。
* **Syscall 行为类别**：支持按照 `PROCESS` (execve), `FILE` (open/mkdir/unlink), `NETWORK` (connect/bind/send/recv), `DEVICE` (ioctl) 过滤。
* **风险评估过滤**：仅展示被本地 AI 评分判定为 `ALERT` 或 `BLOCK` 的异常行为。

### 2.3 Strace-Style 统计与耗时分析
点击任意一条事件，可展开右侧详细抽屉面板：
* 给出类似于 `strace` 工具的调用耗时（Syscall latency）度量。
* 展示参数的原始值与脱敏替换后的对比（如敏感路径显示为 `<CONFIG>`）。
* 导出当前过滤视图下的事件列表为 JSON、JSONL 或 CSV。
